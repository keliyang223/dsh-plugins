# DSH File Write

[English](README.en.md)

DeepSeek Harness Web `0.1.7-rc.1` 的独立插件：在右侧文件预览中编辑文本，并在文件树中右键新建、重命名文件和文件夹，或将条目移入系统废纸篓（Windows 为回收站）。

## 用法

- 在预览的查看方式中选择 **编辑源文件**，即可编辑文本文件并自动保存；`.md`、`.markdown` 文件也通过这一源文件编辑器处理。
- 废纸篓文案按 DSH 宿主系统显示：Windows 宿主显示“移到回收站”，其他系统显示“移到废纸篓”；浏览器系统可能与宿主不同。
- 在文件树中右键**目录**，可选 **新建文件**（输入单个文件名，如 `a.md`）、**新建文件夹**（输入单个文件夹名）、**重命名**或 **移到废纸篓**；右键**普通文件**可选 **重命名**或 **移到废纸篓**，不提供新建操作。重命名仅更改名称，不移动目录层级，若目标名称已存在则拒绝覆盖。文件树空白区域不提供这些操作。移动前须在确认弹窗中确认；目录及其中内容会一起进入系统废纸篓（Windows 为回收站），可从中恢复。移动失败不会自动永久删除。
- 右键**目录**选 **添加文件…**，可通过系统文件选择器导入一个或多个文件；也可以把多个文件拖放到文件树里的目标目录。点击目录选中后，在文件树内按 **Cmd+V**（Windows 为 **Ctrl+V**）尝试粘贴浏览器提供的文件；目录右键 **粘贴** 可尝试读取剪贴板中的图片。若浏览器不提供原生复制的文件（尤其 Finder/资源管理器复制文件或目录），会提示改用“添加文件”或拖放；不支持递归导入文件夹。
- 与 `dsh-file-to-chat` 同时安装时，新建、导入、重命名和移到废纸篓操作会加入同一个右键菜单；单独安装也可使用。

## 安装

```sh
dsh plugin --profile web add "/absolute/path/to/dsh-plugins/dsh-file-write"
```

重启当前 DSH Web 进程并刷新页面，使宿主写入服务和浏览器端编辑器生效。卸载：`dsh plugin --profile web remove dsh-file-write`。

## 安全与限制

- 仅在当前活动会话工作区内写入普通文本文件或创建单层文件夹；尊重会话只读策略。名称只能是单个名称，不能包含 `/`、`\` 或路径穿越。创建文件夹需要本地文件系统后端；并发恶意替换祖先符号链接仍有与删除相同的 TOCTOU 风险。
- 导入文件每个最多 512 MiB，分块暂存后以独占创建方式写入工作区内已有目录；同名文件不会覆盖，逐个显示成功/失败并可取消，临时文件在完成、取消、失败或过期后清理。导入只支持本地文件系统后端；不可信并发进程替换祖先目录时仍有 TOCTOU 风险。新建文件使用“仅在不存在时创建”，不会覆盖同名文件；重命名会检查目标是否存在，但 Node 的跨平台 `rename` 不具备原子“不覆盖”能力：若外部进程恰在最后一次检查后创建同名目标，仍可能发生并发覆盖。请避免在不可信并发修改环境中重命名。保存需要打开时的文件版本，发现其他程序修改后拒绝覆盖并保留草稿。
- 编辑仅支持 UTF-8 且不含 NUL 的文件，原文件与写入文本上限为 2 MiB。大文件、非文本内容和权限不足均不能保存。
- 编辑区只在完整内容及版本读取成功后启用。输入停止约 600 毫秒后自动保存；写入失败或版本冲突时保留草稿并停止重试，继续编辑后才再次尝试。草稿仅在当前页面生命周期内暂存，刷新或关闭页面前请确认显示“已保存”，否则请先复制草稿。冲突不会自动合并。
- 新建、重命名和移到废纸篓均经 DSH 宿主端检查会话与工作区；只读会话禁止这些操作；不能移动工作区根目录或符号链接本身，越界目标会拒绝。使用 `trash` 包调用当前宿主系统的废纸篓/回收站，只支持本地文件系统；不会退回到永久删除。移动前会重新检查路径，移动后确认原路径已消失；如果有恶意进程同时替换祖先目录的符号链接，仍存在 TOCTOU 风险。请勿在不可信的并发修改环境中移动目录。以服务账户运行的 Windows 宿主可能将文件移到服务账户而非桌面用户可见的回收站。

## 开发

```sh
npm run build
npm test
```

`lib/index.js` 是宿主端的受控写入服务；`lib/client.js` 注册文本编辑视图和新建文件菜单。`cordis.patch.yml` 把两端加入 Web profile。
