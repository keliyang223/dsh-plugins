# DSH File Write

[English](README.en.md)

DeepSeek Harness Web `0.1.7-rc.1` 的独立插件：在右侧文件预览中编辑文本，并在文件树中右键新建文件、文件夹或将条目移入系统废纸篓（Windows 为回收站）。

## 用法

- 在预览的查看方式中选择 **编辑源文件**，即可编辑文本文件并自动保存；`.md`、`.markdown` 文件也通过这一源文件编辑器处理。
- 在文件树中右键**目录**，可选 **新建文件**（输入单个文件名，如 `a.md`）、**新建文件夹**（输入单个文件夹名）或 **移到废纸篓**；右键**普通文件**只提供 **移到废纸篓**，不提供新建操作。文件树空白区域不提供这些操作。移动前须在确认弹窗中确认；目录及其中内容会一起进入系统废纸篓（Windows 为回收站），可从中恢复。移动失败不会自动永久删除。
- 与 `dsh-file-to-chat` 同时安装时，增删操作会加入同一个右键菜单；单独安装也可使用。

## 安装

```sh
dsh plugin --profile web add "/absolute/path/to/dsh-plugins/dsh-file-write"
```

重启当前 DSH Web 进程并刷新页面，使宿主写入服务和浏览器端编辑器生效。卸载：`dsh plugin --profile web remove dsh-file-write`。

## 安全与限制

- 仅在当前活动会话工作区内写入普通文本文件或创建单层文件夹；尊重会话只读策略。名称只能是单个名称，不能包含 `/`、`\` 或路径穿越。创建文件夹需要本地文件系统后端；并发恶意替换祖先符号链接仍有与删除相同的 TOCTOU 风险。
- 新建文件使用“仅在不存在时创建”，不会覆盖同名文件；保存需要打开时的文件版本，发现其他程序修改后拒绝覆盖并保留草稿。
- 编辑仅支持 UTF-8 且不含 NUL 的文件，原文件与写入文本上限为 2 MiB。大文件、非文本内容和权限不足均不能保存。
- 编辑区只在完整内容及版本读取成功后启用。输入停止约 600 毫秒后自动保存；写入失败或版本冲突时保留草稿并停止重试，继续编辑后才再次尝试。草稿仅在当前页面生命周期内暂存，刷新或关闭页面前请确认显示“已保存”，否则请先复制草稿。冲突不会自动合并。
- 增改操作经 DSH 宿主端检查会话与工作区；只读会话禁止移动；不能移动工作区根目录或符号链接本身，越界目标会拒绝。使用 `trash` 包调用当前宿主系统的废纸篓/回收站，只支持本地文件系统；不会退回到永久删除。移动前会重新检查路径，移动后确认原路径已消失；如果有恶意进程同时替换祖先目录的符号链接，仍存在 TOCTOU 风险。请勿在不可信的并发修改环境中移动目录。以服务账户运行的 Windows 宿主可能将文件移到服务账户而非桌面用户可见的回收站。

## 开发

```sh
npm run build
npm test
```

`lib/index.js` 是宿主端的受控写入服务；`lib/client.js` 注册文本编辑视图和新建文件菜单。`cordis.patch.yml` 把两端加入 Web profile。
